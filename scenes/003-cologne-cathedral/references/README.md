## 尺寸和建筑档案

- 建筑总长、总宽、西立面、南北塔及拱顶净高取自[科隆大教堂官方尺寸表](https://www.koelner-dom.de/erleben/der-dom-in-zahlen)。
- 屋脊高度取自[欧盟 Nano-Cathedral 项目建筑研究](https://www.nanocathedral.eu/wp-content/uploads/2017/02/Nanocathedral-D1.1-Document-on-historical-architectural-architectural-environmental-knowledge-of-the-buildings-min.pdf)。
- 建造史、五廊平面和三王圣龛参见[联合国教科文组织世界遗产档案](https://whc.unesco.org/en/list/292/)。南横厅彩窗参见[科隆大教堂艺术品档案](https://www.koelner-dom.de/kunstwerke/suedquerhausfenster)。
